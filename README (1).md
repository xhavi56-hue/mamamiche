# Mamamiche

Sitio web de Mamamiche, un bar de micheladas y bebidas preparadas.
Está hecho con HTML, CSS y JavaScript, sin librerías ni herramientas extra.

## Archivos

- `index.html`: el contenido de la página (textos, menú, horario, contacto).
- `style.css`: colores, tipografías, diseño y animaciones.
- `script.js`: hace que las secciones aparezcan al hacer scroll.
- Las imágenes (logo, fotos de las bebidas y captura del mapa) están en la misma carpeta que `index.html`.

## Cómo cambiar datos

- **Precios, nombres y descripciones:** busca el bloque `<article class="tarjeta revelar">` de la bebida en `index.html` y edita el texto.
- **Horario y teléfono:** están en la sección `visitanos` de `index.html`.
- **Mapa:** reemplaza el archivo `mapa.png` por otra captura con el mismo nombre.

## Movimiento

Las animaciones se apagan solas para quien tenga activada la opción de reducir movimiento en su dispositivo.
